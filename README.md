## 📖 О проекте

**Screamer** — шуточный скример для розыгрышей друзей.
Разворачивается на весь экран, проигрывает пугающее видео и сам закрывается через несколько секунд.

## 🎭 Как работает

- 🖥️ Открывается на весь экран
- 😱 Проигрывается скример-видео
- ⏱️ Автоматически закрывается через несколько секунд

> ⚠️ Используй только для безобидных шуток. Антивирус может реагировать ложным срабатыванием.
